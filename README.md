# ColdRcon

Source code of [RconCore.exe](https://github.com/Tiiffi/mcrcon)

Connection Tutorial

  1. Open server.properties
  2. Find enable-rcon=false (change it to true)
  3. Find rcon.password= (add password)
  4. Find rcon.port=25575 (you can leave it 25575)
  5. Open App
  6. Write your server ip
  7. Write rcon port you set on step 4
  8. Write rcon password you set on step 3

If you have exit status 1 when using command check if you entered ip, port, and password right
- - - -
If you still have error that means you using this apps to open ports

Playit.gg
  1. Open website and create new TCP tunnel with rcon port you are using
  2. Then look at ip that you get for this tunnel example example.gl.at.ply.gg:15953
  3. Open app and use ip from playit.gg (like example.gl.at.ply.gg) for Server IP
  4. And use port from playit.gg (like 15953) for Server Port
  5. Write rcon password and click Connect
